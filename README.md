Student Management System

1. Project Description

The Student Management System is a simple C++ program designed to manage student information. It allows the user to enter a student’s name, ID, and three marks. The program calculates the student’s average and determines whether the student passes or fails.

2. Project Objectives

* Enter student information.
* Store student marks.
* Calculate the average of three marks.
* Display student information.
* Determine the student’s result (Pass or Fail).
* Demonstrate Object-Oriented Programming concepts.

3. OOP Concepts Used

1. Classes and Objects

The program uses two classes: Person and Student. An object named student is created from the Student class.

2. Encapsulation

The student ID and marks are declared as private data members to protect the data.

3. Constructors

Constructors are used to initialize the name, ID, and marks.

4. Destructors

Destructors are used when objects are destroyed.

5. Inheritance

The Student class inherits from the Person class.

6. Polymorphism

The program uses a virtual function to allow different behavior through a base class pointer.

7. Virtual Functions

The display() function is declared virtual in the Person class and overridden in the Student class.

8. Function Overloading

The calculateAverage() function has two versions: one calculates the average, and the other calculates the average with an additional bonus.

9. Access Modifiers

The program uses private, protected, and public to control access to class members.

4. Programming Language

C++

5. How the Program Works

1. The user enters the student’s name.
2. The user enters the student ID.
3. The user enters three marks.
4. The program calculates the average.
5. The program displays student information and the result.
